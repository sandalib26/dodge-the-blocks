# 🎮 Dodge the Blocks

A simple browser-based endless runner game built with **HTML, CSS, and JavaScript**.

The goal is simple: **move the player and dodge the falling blocks for as long as possible!**

## 🎮 Live Demo

## ✨ Features

* 🎮 Keyboard controls
* ⬅️ Move left
* ➡️ Move right
* 🔴 Falling obstacles
* 🏆 Score system
* 💥 Collision detection
* 🔄 Restart button
* 🌐 Runs directly in the browser
* 📱 Simple and lightweight

## 🕹️ How to Play

1. Open the game in your browser.
2. Use the **Left Arrow (←)** key to move left.
3. Use the **Right Arrow (→)** key to move right.
4. Avoid the falling red blocks.
5. Your score increases when blocks pass you.
6. If a block hits the player, the game ends.
7. Click **Restart Game** to play again.
